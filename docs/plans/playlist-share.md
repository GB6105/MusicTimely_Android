## 디자인 규칙 (Figma 메모)
- 곡명·아티스트는 확인된 데이터만. 평균 길이로 가짜 목록 금지
- 곡 정보 없음 → "곡 정보를 가져오지 못했어요" + 공유 버튼 비활성
- 목록이 길면 목록 영역만 스크롤, 버튼 하단 고정
- 공유 이미지: 9:16 PNG 1080×1920, 곡 목록 + 총 걸린 시간, 작업 제목 숨김
- 스토리는 여러 장 분할 가능, 순서·중복 재생 보존
- 실제 음원·앨범아트 공유 권리는 구현 전 확인

## 서버 기능 (이 저장소 범위 밖)
이미지 공유 자체는 서버 불필요. 아래를 원할 때만 서버 작업.

| 기능 | 이유 |
|---|---|
| 공유 링크·웹 미리보기(OG 이미지) | 호스팅 필요 |
| 스트리밍 서비스에 실제 플레이리스트 생성 | Spotify·YouTube Music API OAuth, 토큰·시크릿 보관 |
| 플레이리스트·세션 기록 클라우드 백업, 기기 간 동기화 | 저장소·계정 |
| 앨범아트 프록시·캐시, 공유 분석 | 서버 처리 |

- 계정 등록(개발 아님): Meta 앱 ID 불필요 — DEC-A22로 `ADD_TO_STORY` 대신 `ACTION_SEND` 사용 (2026-10-13)
